# 3D Interactive Hostel Room Booking & Mess Wallet System

A smart hostel management platform that combines **3D hostel room visualization**, **room booking**, **mess wallet management**, **face-recognition-based meal attendance**, and **administrative monitoring** into one system.

## 📌 Project Overview

The Hostel Management System is designed to improve the hostel experience for students and simplify hostel administration.

The system allows students to:

- Register and securely log in
- Explore hostel rooms through a 3D interface
- Check room availability
- Select and book rooms
- Make online payments
- Maintain a mess wallet
- Track meal attendance
- View hostel bills and invoices

Wardens can monitor:

- Room occupancy
- Student attendance
- Revenue
- Payments
- Fines

Mess staff can manage and publish the weekly mess menu.

## 🎯 Objectives

- Provide students with an interactive way to view and select hostel rooms.
- Replace manual meal attendance with automated face-scan attendance.
- Charge students only for meals they actually consume.
- Provide a centralized system for rooms, meals, payments and billing.
- Provide wardens with a dashboard for monitoring hostel activities.
